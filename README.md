# IP2-Agent-Hallucination-Rate-Tool-Misuse-Evaluator
FYP for 0206433, a Agentic AI Evaluator with a log parser that scans for user query, agent answer, tool used and Agent signatures, then rearranges the retrieved items in a standardized format. The parsed log then is processed by a local lightweight LLM-as-a-Judge called Llama 3.1 8b. The Local Model is loaded via Ollama and can be swapped.
