# IP2-Agent-Hallucination-Rate-Tool-Misuse-Evaluator
FYP for 0206433, a Agentic AI Evaluator with a log parser that scans for user query, agent answer, tool used and Agent signatures, then rearranges the retrieved items in a standardized format. The parsed log then is processed by a local lightweight LLM-as-a-Judge called Llama 3.1 8b. There is also a dashboard interface that is run locally. Everything can be run offline and no API keys are needed. 
File types accepted : JSON, JSONL, CSV, AutoGPT, SUPERAGI DB export, plaintext logs
